# REX MD-Viewer

> Премиальный веб-ридер и редактор Markdown для экосистемы REX Corp. Закидывай текст или перетаскивай файлы и читай с идеальной типографикой.

**Публичный адрес:** [https://md-viewer.rexcorp.space/](https://md-viewer.rexcorp.space/)  
**Зеркало:** [https://iliabebebe.github.io/md-viewer/](https://iliabebebe.github.io/md-viewer/)  
**Каталог проектов:** [https://hub.rexcorp.space/](https://hub.rexcorp.space/)  

---

## Возможности

- **Мгновенный Drag & Drop:** Перетаскивайте любые `.md`, `.markdown` или `.txt` файлы прямо в окно браузера (поддерживается несколько файлов сразу).
- **Чистый режим чтения (Reader Mode):** Сфокусированный интерфейс без лишних панелей с выверенным ритмом типографики, настраиваемой шириной полосы и выбором шрифтов (Modern Sans, Editorial Serif, JetBrains Mono).
- **Разделенный экран (Split Mode):** Двусторонний редактор и предварительный просмотр с пропорциональной синхронной прокруткой и нумерацией строк.
- **GitHub Admonitions:** Поддержка информационных блоков `[!NOTE]`, `[!TIP]`, `[!IMPORTANT]`, `[!WARNING]`, `[!CAUTION]` с векторными пиктограммами.
- **Математика KaTeX:** Инлайн-формулы `$E=mc^2$` и выносные блоки `$$\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}$$`.
- **Диаграммы Mermaid:** Автоматический рендеринг блок-схем, sequence-диаграмм и графов.
- **Интерактивные списки задач:** Кликабельные чекбоксы `- [ ]` / `- [x]`, синхронизирующие состояние с исходным текстом.
- **Оглавление (TOC) и ScrollSpy:** Автоматическая древовидная структура заголовков со слежением за текущим экраном и статистикой чтения.
- **4 темы оформления:** Obsidian Slate (тёмная), Midnight OLED (абсолютно чёрная), Warm Parchment (книжная бумага), Nordic Clean (светлая).
- **Экспорт:** Скачивание `.md`, автономный `.html`, печать и экспорт в PDF через оптимизированный `@media print`.
- **PWA & Offline:** Готов к автономной работе без интернета благодаря Service Worker.
- **Дизайн без эмодзи:** 100% чистая векторная SVG-графика по стандарту `beautiful-ui-ux` и `unslop`.

## Горячие клавиши

| Сочетание | Действие |
| :--- | :--- |
| `Alt + 1` | Режим чистого чтения (Reader) |
| `Alt + 2` | Разделенный режим (Split: редактор + превью) |
| `Alt + 3` | Режим исходного кода Markdown (Source) |
| `Alt + O` | Открыть / скрыть панель оглавления |
| `Ctrl + O` | Открыть локальный файл |
| `Ctrl + S` | Сохранить и скачать файл `.md` |
| `Ctrl + P` | Печать / экспорт в PDF |
| `Ctrl + N` | Создать новую вкладку документа |
| `?` | Справка по горячим клавишам |

## Архитектура и развёртывание

Проект построен как легковесный клиентский Single Page Application (SPA):
- **Основной хостинг:** Домашний VPS REX Corp (`/var/www/md-viewer/public`) под управлением Nginx и Cloudflare Tunnel.
- **Git-деплой:** При пуше в `vps/main` автоматический post-receive hook обновляет runtime на сервере.
- **Публичный адрес:** [https://md-viewer.rexcorp.space/](https://md-viewer.rexcorp.space/).
- **Зеркало:** GitHub Pages (`origin/main`).
- **Каталог:** Зарегистрирован в REX Hub.
